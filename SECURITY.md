# Security policy

This repository is the source of the static website https://brentawildrace.it.
The site has no login, no forms and no database; it is served by GitHub Pages.

## Reporting a vulnerability

Please **do not open a public issue or pull request** for a security problem.

Report it privately instead, through GitHub:

1. Go to the [Security tab](https://github.com/elibattistoni/brenta-wild-race/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and the page or file it affects.

Only you and the maintainer can see the report. You will get a reply as soon
as possible; this is a volunteer project, so please allow a few days.

## In scope

- The code in this repository and its GitHub Actions workflows
- The website at https://brentawildrace.it

## Out of scope

- External sites the website links to (race registration, social media)
- Reports from automated scanners without a concrete impact
- Missing security headers that GitHub Pages cannot set (for example HSTS)
